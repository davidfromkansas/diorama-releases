# Diorama for macOS

[**Download the latest release**](https://github.com/davidfromkansas/diorama-releases/releases/latest)

Diorama brings local coding conversations and projects into one macOS workspace.

## Install

1. Download the `.dmg` installer from the latest release.
2. Open it and drag **Diorama** into **Applications**.
3. Open Diorama and connect OpenAI or Claude. GitHub connection is optional.

Requires **Apple Silicon (M1 or newer)** and **macOS 14 or later**. Releases are Developer ID signed and Apple notarized.

The corresponding official **Codex CLI or Claude Code CLI** must be installed and authenticated. Desktop apps are optional. Onboarding provides installation guidance; Claude subscription authentication is supported.

This repository contains installation documentation and downloadable releases only. Application source, build infrastructure, and signing credentials are maintained separately. GitHub’s automatically generated “Source code” archives contain only this repository’s documentation; choose the `.dmg` to install Diorama.

Early testing builds may have setup or compatibility issues. See each release’s notes for limitations. No GitHub account is required to download.
